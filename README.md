# Halil Efe Kutlu — Quest Log

Bu proje, Balıkesir Üniversitesi Bilgisayar Mühendisliği bölümü İnternet Programlama dersi final ödevi için hazırlanmış yaratıcı bir kişisel web sayfasıdır.

Klasik bir portfolyo sayfası yerine; ilgi alanlarımı, şu anda nelerle ilgilendiğimi, gelecek hedeflerimi ve dijital dünyamı daha etkileşimli bir şekilde anlatan bir web deneyimi oluşturmayı amaçladım.

## Canlı Demo

[Site Linki](https://halilefekutlu.github.io/halil-digital-journey/)

## Proje Hakkında

**Quest Log**, oyunlardan ve kişisel gelişim mantığından ilham alan bir kişisel web sayfasıdır. Sayfa içerisinde kendimi sadece yazılarla değil; renk geçişleri, etkileşimli bölümler, ilgi haritası, mini terminal modu ve modern arayüz detaylarıyla tanıtmaya çalıştım.

Bu proje; HTML, CSS, JavaScript ve React/Next.js yapısını kullanarak hazırlanmıştır.

## Özellikler

* Kaydırmaya bağlı yumuşak arka plan renk geçişleri
* Sabit üst navigasyon menüsü
* Aktif bölüm göstergesi
* Türkçe / İngilizce dil geçişi
* Etkileşimli “Beynimin Küçük Haritası” bölümü
* Geek Mode içerisinde mini terminal deneyimi
* WhatsApp iletişim butonu
* Mobil uyumlu modern tasarım
* Yukarı çık butonu
* Kişisel ilgi alanları, hedefler ve şu an odaklanılan konular
